# Elevate Labs - Task 4: Classification with Logistic Regression

## Objective

Build a binary classification model using Logistic Regression.

## Dataset

Breast Cancer Wisconsin Dataset from Scikit-learn.

The dataset contains numerical features related to breast cancer diagnosis and a binary target variable.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Steps Performed

1. Imported the required Python libraries.
2. Loaded the Breast Cancer Wisconsin dataset using Scikit-learn.
3. Explored the dataset structure and statistical information.
4. Checked for missing values.
5. Separated features and target variable.
6. Split the dataset into training and testing sets.
7. Standardized the numerical features using StandardScaler.
8. Built a Logistic Regression model.
9. Generated predictions and prediction probabilities.
10. Evaluated the model using accuracy, confusion matrix, precision and recall.
11. Calculated the ROC-AUC score.
12. Plotted the ROC curve.
13. Explained the sigmoid function.
14. Demonstrated classification threshold tuning.
15. Examined Logistic Regression coefficients.

## Model Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- Confusion Matrix
- ROC-AUC
- ROC Curve

## Conclusion

Logistic Regression was successfully implemented for binary classification using the Breast Cancer Wisconsin dataset. The model was evaluated using multiple classification metrics, and threshold tuning was demonstrated to understand its effect on model predictions.
